## 1. Главная таблица (лидерборд)

### 1.1. Популяции

- **P_all** — популяция E7: `data/demo/runs.parquet`, `submitted == 1`, 7 864 прогона, сортировка по `run_id`.
- **P_ne (основная)** — P_all без прогонов с пустым патчем: `p_empty == 1` в `outputs/e13_patch_features.csv.gz`

### 1.2. Модели

Обучение как в E7: `StandardScaler` на обучающих строках + `LogisticRegression(C=1, max_iter=5000)`, риск out-of-fold,
без подбора — если не сказано иное.

| строка | входы | замечание |
|---|---|---|

Описательно, только в P_all: правило «пустой патч — на проверку первым, остальное по `M+S`».

### 1.3. Метрики

- **Общий AUROC.**
- **AUROC внутри задачи** — пары (нерешённый, решённый) одной задачи, пулом, равенства 1/2 (`e7.pair_counts`);
  макро-среднее по задачам — дополнительно. Для `D` и `D_c` не приводится: внутри задачи сложность постоянна по
  замыслу, а вариант «без своей модели» механически смещён (у провального прогона из числителя убран его собственный
  провал).
- **precision@5/10/20%** и **recall@10%**: верхние `k = ceil(доля · n)` по риску. Равенства на границе отбора — по
  математическому ожиданию при случайном порядке внутри равных (рецензия, М9; для непрерывных рисков совпадает с E7).
- **Доля нерешённых** — база precision.

### 1.4. Интервалы

Кластерный бутстрэп по задачам: 1000 выборок, `default_rng(42)`, общие для всех моделей и метрик популяции (код E7).
Разности — на тех же выборках.

### 1.5. Разности (обе популяции; общий AUROC, внутри задачи, precision@10%)

`(M+S) − (M+N)`, `(M+S) − (M+LEN)`, `(M+S) − M`, `(D+M+S) − (D+M)`.

### 1.6. Правила чтения

- «Структура добавляет к модели и длине» — если нижняя граница ДИ `(M+S) − (M+LEN)` по общему AUROC в P_ne больше 0;
  иначе — «от модели и длины не отличима».
- Главное число полезности в документах — P_ne (`M+S`, precision@10%); P_all — для сравнения, оба числа рядом.

### 1.7. Проверки воспроизведения (СТОП при расхождении в третьем знаке)

P_all: `S` 0.662 / 0.640 (общий / внутри задачи); `M+S` 0.685 и precision@10% 0.656; `M` внутри задачи 0.742.

### 2.2. Предсказатели

Блоки: `S` (21), `LEN` (4), `O` (19 признаков основного набора E10, `outputs/e10_features.csv.gz`; попытки без
команд — нули, как в E10), `S+O`.

| вариант обучения | как | происхождение |
|---|---|---|
| **T1 — на трёх настройках** | одна модель на все три настройки; `GroupKFold(5, shuffle, 42)` по задаче на объединённой популяции | E8 P2 |
| **T2 — внутри настройки** | своя модель на каждую настройку; фолды E9/E10 | E9 P2, E10 |
| T3 (дополнительно) — внутри настройки, только законченные | как T2, но обучение только на законченных попытках (те же фолды) | рецензия |

Попытки с ошибкой оценки получают риск модели фолда своей задачи (как в E9). База **«попытка не закончена»**:
риск = 1 − законченность, без обучения. Описательно — одно число шагов.

### 2.3. AUROC внутри единицы (E8, E10)

Пары (нерешённая, решённая) одной единицы, пулом, равенства 1/2 (код `e8.unit_counts`), на наборах пар:
- **все пары** (как в E8 и E10);
- **ЗЗ** — обе попытки законченные (основной новый разрез);
- описательно: **ЗН** — одна законченная, одна нет; **НН** — обе незаконченные.

Охват: каждая настройка и три вместе. ДИ — бутстрэп по единицам, 1000, `default_rng(42)` (E8, E10). Разности на тех же
выборках: `S` − «не закончена» (все пары); `S+O` − `S` (ЗЗ); T1 − T2 для `S` (все пары и ЗЗ).

### 2.4. Выбор одной попытки из k (E9, E10)

Подмножества E9 (`e9.subsets()`: 200 на задачу, `default_rng(42)`), k = 2, 3, 5, 10; главное k = 5. Правила (точное
ожидание по равенствам, как в E9):
- случайная; случайная среди отправивших (база E9);
- **случайная среди законченных** — среди отправленных законченных попыток подмножества; если таких нет — среди
  отправленных (база «попытка не закончена»);
- наименьший риск среди отправленных: `S`-T1, `S`-T2, `S+O`-T1, `S+O`-T2;
- наименьший риск **среди законченных** (если законченных нет — среди отправленных): `S`-T1, `S`-T2, `S`-T3,
  `S+O`-T1, `S+O`-T2;
- oracle (решена хотя бы одна).

Δ в п.п.: правила по риску и «случайная среди законченных» — к «случайной среди отправивших»; правила «среди
законченных» — к «случайной среди законченных». ДИ — бутстрэп по задачам, 1000 (код E9).

### 2.5. Проверки воспроизведения (СТОП при расхождении в третьем знаке)

Внутри единицы, все пары: `S`-T1 — devstral 0.578, три вместе 0.533; `LEN`-T1 — три вместе 0.496; `S`-T2 — devstral

### 2.6. Правила чтения

- **Сигнал среди законченных попыток** у настройки по блоку (`S`, `O`, `S+O`): «установлен» — нижняя граница ДИ AUROC

## 3. Разложение дисперсии исхода на повторах и потолок AUROC внутри единицы

### 3.1. Популяция

Основная — популяция E8 (13 778 попыток), `y = 1` — не решено. Дополнительно — все 15 000 попыток, `y = 1 − solved`.

### 3.2. Модель

Смешанная логистическая модель:

`logit P(y = 1) = μ_s + a_t + c_ts`, `a_t ~ N(0, σ²_задача)`, `c_ts ~ N(0, σ²_задача×модель)`, независимы.

- `μ_s` — фиксированные эффекты трёх настроек (дисперсию случайного эффекта по трём уровням не оценить).
- Попытки внутри единицы условно независимы, поэтому правдоподобие считается по биномиальным счётам единиц.
- **Оценка — максимум правдоподобия.** Интеграл — вложенная квадратура Гаусса–Эрмита (внутренний по `c_ts`, внешний по
  `a_t`), 40 узлов на уровень. Оптимизатор — L-BFGS-B по `(μ_1..3, log σ_задача, log σ_задача×модель)`.
- **Проверки:** при 60 узлах параметры совпадают с точностью 0.01; восстановление параметров на одной выборке,
  смоделированной из оценённых (приводится).

### 3.3. Доли на латентной шкале

- `V_модель = Σ_s w_s (μ_s − μ̄)²`, `w_s` — доля попыток настройки;
- `V_задача = σ²_задача`, `V_задача×модель = σ²_задача×модель`;
- `V_попытка = π²/3` — остаточная дисперсия логистической модели.

Доля = `V / ΣV`. Дополнительно по каждой настройке — модель `μ + u_t`: доля попытки `π²/3 / (σ²_u + π²/3)`.

### 3.4. Наблюдаемая шкала (без модели, дополнительно)

- `Var(y)` = между единицами + внутри единицы.
- **Внутри единицы:** `Σ_u n_u · p̂_u(1 − p̂_u) · n_u/(n_u − 1) / N` (несмещённая оценка `p_u(1 − p_u)`).
- **Между единицами** — двухфакторный дисперсионный анализ средних единиц по задачам, где есть все три единицы:
  модель (дисперсия средних настроек), задача, задача × модель. Из оценок вычитается выборочная дисперсия средних
  единиц `p̂(1 − p̂)/(n − 1)`.

### 3.5. Интервалы

Бутстрэп по задачам (задача берётся со всеми своими единицами), `default_rng(42)`:
- модель 3.2 — 200 выборок, 20 узлов, старт из точечной оценки (одна подгонка с 40 узлами — около 15 с);
- наблюдаемая шкала — 1000 выборок.

### 3.6. Потолок AUROC внутри единицы при шуме оценки

Шум, который не может снять никакой предсказатель по траектории, — шум самой оценки: при одном и том же патче
скрытые тесты иногда дают разный исход. Оценивается по одинаковым патчам внутри единицы (`generated_diff` из сырых
данных KTH).

1. **Расхождение на одинаковых патчах.** Пары попыток с меткой в одной единице с побайтно одинаковым непустым
   `generated_diff` (после `strip`). `d` — доля пар с разной меткой; по настройкам и вместе. ДИ — бутстрэп по
   единицам, 1000.
2. **Модель шума.** Каждая оценка независимо даёт неверную метку с вероятностью ε; одинаковые патчи имеют общий
   истинный исход. Тогда `d = 2ε(1 − ε)` и `ε = (1 − √(1 − 2d)) / 2`.
3. **Прямая граница.** `s` — доля пар (нерешённая, решённая) внутри единиц с одинаковым патчем. При данном патче метка
   не зависит от траектории, поэтому ожидаемый вклад такой пары для любого предсказателя — 0.5, и потолок ≤ `1 − s/2`.
4. **Потолок по модели.** Моделирование из оценённой модели 3.2: по настройке `μ_s`, `σ`; 500 задач, 10 попыток,
   200 повторов. Истинный исход `t`, наблюдаемая метка `y = t XOR Bern(ε)`. Считается AUROC внутри единицы
   предсказателя, знающего `t`, по парам с разными `y`. Значения: для ε̂ и концов его ДИ, а также для ε = 0.01, 0.02,
   0.05, 0.10.
   - **Приближение:** модель 3.2 оценена по наблюдаемым меткам, и разброс внутри единицы уже включает шум. Это
     записывается.
5. **Дополнительно — «оракул единицы».** В той же модели — общий AUROC предсказателя, знающего истинную вероятность
   единицы `p_u` и ничего не знающего о попытке. Аналог потолка `D` на лидерборде.

### 3.7. Правила чтения

- Потолок 3.6 больше 0.9 — исход внутри единицы почти полностью определяется попыткой (патчем). Тогда слабый сигнал
  (0.53–0.58) — ограничение предсказателей, а не шум данных.
- Потолок меньше 0.7 — внутри единицы доминирует шум оценки, и слабый сигнал ожидаем при любых признаках.
- Между этими значениями — описательно.
- Ограничение: одинаковые патчи — не случайная выборка попыток (чаще простые и типовые исправления). Это записывается.
