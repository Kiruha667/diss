# E6 — блок 1: починка признаков

Подпопуляция E5: траектории с заявлением об успехе (G0 `has_claim`), n = 2877 (недостоверных 1000, достоверных 1877, доля недостоверных 0.348). AUROC признака в одиночку — по всей подпопуляции без CV (описательно), > 0.5 — признак выше у недостоверных заявлений; 95% ДИ — бутстрэп по задачам, 1000 повторов, seed 42. «Срабатывает» — значение отличается от тривиального (≠ 0; для серий `max_run_length`, `max_phase_run` — > 1; для долей уникальных `distinct_ratio`, `distinct_cmd_ratio`, которые ≤ 1, — < 1); признак, срабатывающий менее чем в 5% траекторий, считается неработающим и исключается из моделей. Столбец «≠ 0» — буквальная доля ненулевых значений. Правила зафиксированы до результатов (коммит d0343fb, docstring `src/e6_refine.py`); единственная правка после первого прогона — ошибка реализации: для `distinct_ratio` срабатывание проверялось как > 1 (всегда ложно), исправлено на «отличается от 1», как в правиле.

## 1.2. Коды возврата: диагностика

- В сыром логе коды возврата **есть**: тег `<returncode>` содержат 20763 из 20763 выводов инструментов в локально доступных сырых траекториях (355 шт.; v1 — сообщения role=user, v2 — role=tool). Адаптер E0 сохраняет ненулевой код префиксом `returncode: N`; доля выводов с ненулевым кодом по всем 447594 выводам 7975 траекторий: v1.x 7.6%–15.1% по версиям агента, v2.x 13.3%.
- Значит, `nonzero_rc_share` извлекался правильно. Его коэффициент в E5 (+0.0004) близок к нулю потому, что признак не различает классы: среднее 0.104 у достоверных против 0.099 у недостоверных, AUROC в одиночку 0.484.
- **Использован вариант с кодами возврата** (коды есть, прокси не нужен): `nonzero_rc_share` (E5, без изменений) и новый `verify_fail_share` — доля шагов верификации с ненулевым кодом.
- Текстовый прокси (Traceback, Error, No such file, command not found, SyntaxError, FAILED, ненулевой exit status) посчитан только для сверки, в модели не входит. По 151710 шагам с выводом: ненулевой код у 11.3%, текстовые признаки ошибки у 20.0%; совпадают на 84.1% шагов (оба — 7.7%, только код — 3.6%, только текст — 12.2%). Расхождение ожидаемо: код возврата конвейера — код последней команды (`pytest ... | tail` даёт 0), а текст ловит и напечатанные, но обработанные ошибки.
