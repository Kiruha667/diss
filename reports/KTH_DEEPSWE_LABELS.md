# Метки DeepSWE-Preview в ASSERT-KTH относятся к другой системе — доказательства и решение

Дата: 2026-11-12. Данные: `ASSERT-KTH/agentic-evals-artifacts`, ревизия `5db0c4b6…` (`data/raw/agentic_evals/`).
Проверка воспроизводится без вызовов API и загрузок:
- `python -m src.kth_deepswe_labels` → `outputs/kth_deepswe_labels.json` (разделы 1–3 ниже);
- `python -m src.e15_consolidation labels` → `outputs/e15_label_check.json` (первая версия проверки, E15, раздел 3.4).

Данные и метки не менялись.

## Что проверялось

В каждой папке настройки лежат траектории nano-agent (`run_k/detailed_predictions.jsonl`, с итоговым патчем
`generated_diff`) и один файл результатов харнесса SWE-bench на прогон (`run_k/<имя>.json`: `resolved_ids`,
`unresolved_ids`, `empty_patch_ids`, `error_ids`). Метка попытки берётся из файла результатов. Если файл — оценка патчей
этих траекторий, то:
1. файл назван по прогону nano-agent;
2. попытка без патча стоит в `empty_patch_ids`, а попытка с патчем — нет;
3. у попытки без патча нет метки «решено» или «не решено»;
4. одинаковые патчи одной задачи получают одинаковую метку (с точностью до шума оценки).

Контроль — две другие настройки того же набора и каркаса (Qwen3-32B, devstral-2512).

## 2. Патч в траектории и статус в файле результатов

Все попытки 10 прогонов (по 500 задач), `outputs/kth_deepswe_labels.json`, поле `trajectory_patch_x_result_status`:

| настройка | без патча → `empty_patch_ids` | без патча → «решено» | без патча → «не решено» | с патчем → `empty_patch_ids` | с патчем → решено / не решено / ошибка |
|---|---|---|---|---|---|
| Qwen3-32B | 742 | 0 | 0 | 0 | 819 / 3 428 / 11 |
| devstral-2512 | 21 | 0 | 0 | 0 | 3 177 / 1 801 / 1 |
| **DeepSWE-Preview** | 179 | **193** | **775** | **246** | 1 376 / 2 209 / 22 |

- У Qwen3-32B и devstral-2512 число попыток без патча в траекториях совпадает с длиной `empty_patch_ids` в каждом из
  10 прогонов (поле `per_run`).
- У DeepSWE-Preview — нет ни в одном прогоне: попыток без патча 105–126 на прогон, в `empty_patch_ids` — 39–54.
- 968 попыток DeepSWE-Preview без патча имеют метку; 193 из них отмечены как **решённые**. Решить задачу без патча
  нельзя.
- 246 попыток с патчем стоят в файле как «пустой патч».

## 3. Одинаковые патчи — разные метки

Пары попыток одной единицы (настройка × задача) с побайтно одинаковым непустым патчем (после обрезки пробелов):

| настройка | пар | с разной меткой | доля |
|---|---|---|---|
| Qwen3-32B | 2 276 | 4 | 0.002 |
| devstral-2512 | 2 609 | 0 | 0.000 |
| **DeepSWE-Preview** | 2 437 | **450** | **0.185** |

Пример (E15, раздел 3.4): `pytest-dev__pytest-5809` — один и тот же патч в 9 попытках; run 0–4 не решены, run 5, 7, 8,
9 — решены. Если бы метки оценивали эти патчи, расхождение было бы на уровне шума оценки, как у двух других настроек.

## 4. Согласуется с прежними числами

У DeepSWE-Preview предсказатели по траектории внутри единицы ниже 0.5: `S` при обучении внутри настройки 0.473 (E15,
раздел 2.3), `S` с лидерборда без дообучения 0.458 [0.428; 0.487] (E8). Само по себе это не доказательство, но
согласуется с тем, что метки с траекториями не связаны.

## Вывод

Метки настройки nano-agent × DeepSWE-Preview (t = 0.6) не являются оценкой патчей её траекторий. Вероятнее всего, это
результаты оценки другого прогона той же модели (R2E-Gym, температура 0), положенные в папку nano-agent. Установить,
какие именно, по данным набора нельзя; для этого нужно обращение к авторам ASSERT-KTH.

## Решение (автор, 2026-11-12)

- DeepSWE-Preview **исключается из основного анализа повторов**. Основные числа E8, E9, E10 и E15 (части 2 и 3) — по
  двум настройкам: Qwen3-32B и devstral-2512; охват «две вместе» вместо «три вместе».
- Пересчёт — тем же кодом, без новых протоколов: это исключение недействительных данных. Оно записано как отступление в
  `reports/E8_PROTOCOL.md` (раздел «Отступление 2026-11-12») и `reports/E15_PROTOCOL.md` (то же).
- Код: `ANALYSIS_SETTINGS` в `src/adapters/agentic_evals.py`. Загрузка данных (сборка E8, разбор проверок E10) по-прежнему
  охватывает все три настройки.
- Прежние числа с DeepSWE-Preview — в приложениях отчётов E8, E9, E10, E15; их выходы — `outputs/kth_with_deepswe/`.
  Воспроизведение тем же кодом: переменная окружения `KTH_WITH_DEEPSWE=1`.
- Не затронуты: E11, E11b, E16 (только devstral-2512); лидерборд (E7, E12–E15 часть 1); E13 на KTH (только devstral).
