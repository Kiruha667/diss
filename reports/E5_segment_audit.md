# E5 — этап 1 (шлюз): аудит длины сегмента после последней правки

Подпопуляция: траектории, где финальное сообщение заявляет успех (G0 `has_claim`), n = 2877 (недостоверных — провал по тестам — 1000, достоверных 1877).
Сегмент — шаги агента строго после последнего шага с правкой (правила G0); длина в шагах и во фрагментах reason_sent E1 (предложения прозы + строки кода, очистка E1).

## Распределение длины сегмента (мин / 25% / медиана / 75% / 90%)

| популяция | n | шагов | предложений |
|---|---|---|---|
| все заявившие | 2877 | 0 / 2 / 3 / 6 / 12 | 0 / 13 / 23 / 45 / 103 |
| достоверные (успех) | 1877 | 0 / 2 / 3 / 6 / 13 | 0 / 13 / 23 / 44 / 97 |
| недостоверные (провал) | 1000 | 0 / 2 / 3 / 5 / 10 | 0 / 14 / 24 / 46 / 134 |

- Сегмент пуст (правка была последним действием): 0.1% (достоверные 0.1%, недостоверные 0.3%).
- Правок не было вовсе (сегмент = вся траектория): 63.
- Доля сегментов ≥ 50 / ≥ 100 / ≥ 200 предложений: 22.7% / 10.8% / 3.7%.

## Решение по шлюзу

Медиана длины сегмента: **23 предложений**. Правило: ≥ 200 → N = 200, d = 4; 100–200 → N = 100, d = 4; 50–100 → N = 50, d = 3 (оценка смещена); < 50 → H1 на сегменте не проверяется.

**Решение: H1 на сегменте НЕ проверяется** — это результат: аппарат перестановочной энтропии неприменим к объекту такой длины (при n < 50 смещение оценки H велико, см. AGENTS.md п. 1.1 и требование n > 5·d!). Переход к этапу 3.
