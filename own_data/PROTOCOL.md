## 5. Ключ API

- Ключ берётся из переменной окружения **`ZAI_API_KEY`** и никогда не пишется в файлы: ни в конфиг, ни в журналы,
  ни в репозиторий.
- Ключ **не передаётся через `model_kwargs`**: mini-swe-agent сохраняет конфиг целиком в `info.config` каждой
  траектории — так ключ попал в публичный корпус. Его читает litellm из окружения процесса.
- Перед записью траектории и любых производных файлов — проверка, что значение ключа в них не встречается; при
  совпадении прогон останавливается, файл не сохраняется.

## 6. Запасной вариант

Если glm-4.6 недоступна у z.ai — `devstral-small-2512` (конфиг прогона `20251209_mini-v1.17.2_devstral-small-2512`,
mini-swe-agent 1.17.1 по траекториям) с **temperature 1.0**. В корпусе у этой модели 0.0, поэтому это отступление от
корпуса и требует версии протокола **1.1** с новыми опорными значениями. Для справки (тот же расчёт): на 36 задачах
пула devstral-small-2512 решила 12 из 36 отправленных (0.333, коридор [0.133; 0.533]), медиана 74.5 шага (коридор
[52.2; 96.9]).

## 7. Отклонённые варианты

- `devstral-small-2512` как основная модель — в корпусе temperature 0.0: ненулевая температура требует отступления от корпуса (оставлена запасной, раздел 6).
- `minimax-m2` — в корпусе temperature 0.0, своя версия каркаса (1.16.0) и формат `<bash_code>`; дороже glm-4.6 (медиана $0.195 против $0.081, среднее $0.43 против $0.10).
- Конфиг прогонов v2 (mini-swe-agent 2.1.0) — прогона кандидатов с этим конфигом в корпусе нет, проверка воспроизводимости невозможна.

## 8. Вопросы, обнаруженные при закрытии TODO (до smoke-теста)

1. **Аппаратная виртуализация выключена** (`systeminfo`: «Virtualization Enabled In Firmware: No»; процессор
   i5-3230M её поддерживает: VM Monitor Mode Extensions и SLAT — Yes; BIOS Lenovo 71CN45WW v1.18). Без неё WSL2 и
   Docker Engine не работают. Включается только вручную в настройках BIOS при загрузке (пункт Intel Virtualization
   Technology). Windows 10 build 19044 поддерживает WSL2.
2. **Реестр моделей litellm.** Дословный конфиг ссылается на `model.litellm_model_registry:
   /home/klieret/litellm_model_registry.json` — файл на машине того, кто запускал прогон корпуса; его содержимого в
   данных нет. По нему litellm определяет провайдера и цены `glm-4.6`, а от цен зависят `instance_cost` и срабатывание
   `cost_limit`. Предлагаемое решение (подтвердить до smoke-теста): создать файл по тому же пути внутри WSL с ценами
   z.ai для glm-4.6 — конфиг остаётся дословным; содержимое файла и его SHA256 записать в `LOG.md`.
3. **Версия litellm** у mini-swe-agent 1.17.1 не закреплена (`litellm>=1.75.5`): закрепить при установке и записывать.
