## 4. Что это значит (формулировки — `01_thesis_and_claims.md`, У1–У4)

- Модель по траектории полезна для отбора: при проверке десятой части прогонов доля нерешённых среди отобранных
  вдвое выше базовой (лифт {{e15.lift.ne|v}}); recall@10% {{e15.ne.MS.rec|v}} при наибольшем возможном
  {{e15.ne.maxrec|v}} {{src:e15.lift.ne}} {{src:e15.ne.MS}} {{src:e15.ne.maxrec}}.
- Почти весь эффект дают модель агента и длина: «`M` + длина» не хуже `M+S`.
- Сложность задачи по исходам других моделей одна объясняет больше, чем любая модель по траектории; это потолок, а не
  инструмент (нужны исходы других моделей на той же задаче).
- Внутри задачи `M+S` хуже одного знания модели: модель, обученная на общей функции потерь, внутри задачи ранжирует
  хуже. При обучении с фиксированными эффектами задачи разность {{rev.ms_m.fe}} — `S` внутри задачи не вредит, но и
  ничего не добавляет (рецензия, С2; посчитано с пустыми патчами).
- Высокое `M` внутри задачи — не свойство траекторий: аддитивная модель «сложность задачи + сила модели» даёт
  {{rev.m.additive}} (рецензия, С2).
- **Почему `S` дублирует `M`: `S` — отпечаток модели.** По `S` логистическая регрессия определяет связку из
  {{e0.combos|v}} в {{rev.fp.combo|v}} случаев (случайно {{rev.fp.chance|v}}), поколение каркаса — с AUROC
  {{rev.fp.gen|v}} {{src:rev.fp.combo}} {{src:rev.fp.gen}} {{src:e0.combos}} (рецензия, С2).
- **Тексты агента к `M+S` ничего не добавляют** (E7; рецензия, С5): финальное сообщение {{e7.ne.A}}, рассуждения
  {{e7.ne.R}}; финальное сообщение внутри задачи различение даже ухудшает ({{e7.ne.A.within}}).
- Рисунок 1 (`10_figures_tables.md`): precision@10% по моделям против базовой доли и потолка.
