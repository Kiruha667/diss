# Набор для статьи (paper kit)

Материалы для текста статьи (IEEE, конференция, английский) и глав диссертации. Всё собрано из отчётов
(`reports/`), выходов (`outputs/`) и независимой рецензии (`review/REVIEW.md`); новых расчётов здесь нет, кроме
рисунков, построенных из `outputs/`.

## Что в наборе и порядок чтения

| файл | что в нём |
|---|---|
| `01_thesis_and_claims.md` | **начать отсюда**: главный тезис; утверждения со статусом, числом, источником, допустимой (EN) и недопустимыми формулировками |
| `11_paper_outline.md` | план статьи: разделы, объём, утверждения, таблицы и рисунки |
| `03_data.md` | данные, популяции, исключения (неотправленные, пустые патчи, DeepSWE-Preview), шум меток |
| `04_methods.md` | постановка, признаки, разметка фаз, модель, три уровня оценки, метрики, бутстрэп, протоколы |
| `05_results_decomposition.md` | главная таблица: сложность задачи (потолок), `M`, «`M` + длина», `S`, `M+S`; precision и recall |
| `06_results_run_level.md` | повторы: все пары и пары законченных попыток, выбор из k, разложение дисперсии, потолок |
| `07_results_agent_words.md` | спонтанное заявление (G0), самооценка (E11, E11b, E16) |
| `08_transfer_limitations.md` | перенос (E13, E14), насыщение бенчмарка, угрозы валидности |
| `09_negative_results.md` | отрицательные результаты для Discussion и диссертации |

## Правила для автора текста

1. **Числа — только из `12_numbers_index.md`**, без переокругления; рядом с каждым числом в наборе стоит
   `[источник: файл, стр. N]` — строка файла в репозитории, где это число записано.
2. **Сила формулировок — по `01_thesis_and_claims.md`.** Статусы: подтверждено / на границе / наблюдение / не
   установлено. Недопустимые формулировки не использовать.
3. **Повторы KTH — две настройки** (Qwen3-32B, devstral-2512). Числа «три вместе» и любые числа DeepSWE-Preview не
   использовать.
4. **Главное число отбора — без пустых патчей** ({{e15.ne.MS.p10}}); число с пустыми патчами — только для сравнения.
5. **Литература — только `references.bib`.** Числа чужих работ — из `docs/LITERATURE.md` (по страницам arXiv; перед
   подачей сверить с PDF).
6. **Отрицательные результаты — прямо**, без «novel», «significantly» без теста.
7. Где набор молчит — `[TODO: …]`.

## Как устроен набор

- Файлы набора генерируются: `python -m src.paper_kit.build build` из шаблонов `src/paper_kit/templates/` и
  спецификации чисел `src/paper_kit/numbers.py` (ключ → значение, смысл, файл-источник, якорная строка). Сборка
  останавливается, если якорь не единственный в файле или значения нет на его строке. Правки вносить в шаблоны и
  спецификацию, затем собрать и проверить.
- Проверка: `python -m src.paper_kit.build check` → `CHECK.md`.
- Рисунки: `python -m src.paper_figures` → `figures/`.
- Источники чисел: `reports/` и `outputs/`; рецензия `review/REVIEW.md` (числа, которых нет в отчётах: парадокс
  Симпсона в G0, мощность проверки G0, ρ при обучении внутри связки, разброс AUROC по связкам, план на страницы);
  `docs/LITERATURE.md` — только числа чужих работ.
