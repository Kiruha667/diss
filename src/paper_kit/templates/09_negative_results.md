# 09. Отрицательные результаты (для диссертации и Discussion)

По нескольку строк; в статье — абзац в Discussion. Числа — из отчётов; числа лидерборда — по популяции статьи
(пересчёт, разделы «Популяция статьи» в отчётах E7, E12, E13).

- **Итерация 1: хаотичность семантических траекторий** (эмбеддинги предложений рассуждений, перестановочная энтропия,
  статистическая сложность; сетка конфигураций). Прирост над длиной {{e4.delta}}, критерий не выполнен; после
  поправки Бенджамини–Хохберга значимы {{e4.bh}}. Ряды рассуждений слишком короткие для этих мер.
- **Описание задачи (E12).** Эмбеддинг описания один даёт {{e12.ne.t2}}; к `M+S` добавляет {{e12.ne.diff}}. Формулировать «в
  нашем представлении описания» (у Ge et al. другое представление и постановка).
- **Текст агента (E7; рецензия, С5).** К `M+S` финальное сообщение (A) и рассуждения (R) ничего не добавляют: A
  {{e7.ne.A}}, R {{e7.ne.R}} по общему AUROC; внутри задачи A различение ухудшает ({{e7.ne.A.within}}). Прирост в
  критерии г протокола (A {{e7.ne.A.tms}}, R {{e7.ne.R.tms}}) посчитан относительно `T+M+S` ({{e7.ne.TMS}}), которая
  слабее `M+S`, — следствие слабой базы, а не вклад текста. TF-IDF описания задачи на невиданных задачах один даёт
  {{e7.ne.T}}.
- **Признаки патча без эталона (E13).** (`M+S+P`) − (`M+S`): {{e13.ne.P}} по общему AUROC — критерий выполнен, но внутри
  задачи {{e13.ne.P.within}}: прирост — про размеры патча и модель, не про попытку. Состав признаков зависит от формата
  логов.
- **Бустинг (E15).** Градиентный бустинг по «модель + log шагов» даёт {{e15.ne.MNgbm}} — не лучше регрессии
  «модель + log шагов» ({{e15.ne.MN}}). Нелинейность не спасает.
- **Выбор лучшей попытки по структуре (E9, E15).** Сверх правила «взять законченную попытку» выбор по `S` ничего не
  добавляет ({{e15k.sel.dev.s1fin}} при обучении на двух вместе); при обучении внутри настройки выбор по `S` не
  отличается от случайной среди отправивших ({{e9.dev.p2}}). Формулировка — `01`, У9; не «не лучше случайного» без
  схемы обучения.
- **Самооценка с «Be honest» (E11b)** — у законченных попыток не отличается от случайной ({{e11b.c4}}; интервал
  включает половину; `07_results_agent_words.md`).
