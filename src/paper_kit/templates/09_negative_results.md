# 09. Отрицательные результаты (для диссертации и Discussion)

По нескольку строк; в статье — абзац в Discussion. Числа — из отчётов.

- **Итерация 1: хаотичность семантических траекторий** (эмбеддинги предложений рассуждений, перестановочная энтропия,
  статистическая сложность; сетка конфигураций). Прирост над длиной {{e4.delta}}, критерий не выполнен; после
  поправки Бенджамини–Хохберга значимы {{e4.bh}}. Ряды рассуждений слишком короткие для этих мер.
- **Описание задачи (E12).** Эмбеддинг описания один даёт {{e12.t2}}; к `M+S` добавляет {{e12.diff}}. Формулировать «в
  нашем представлении описания» (у Ge et al. другое представление и постановка).
- **Текст агента (E7, критерий г).** Финальное сообщение и рассуждения добавляют к модели «задача + модель + структура»
  малый прирост общего AUROC (A {{e7.A}}, R {{e7.R}}), но не различение внутри задачи. TF-IDF описания задачи на
  невиданных задачах один даёт {{e7.T}}.
- **Признаки патча без эталона (E13).** (`M+S+P`) − (`M+S`): {{e13.P}} по общему AUROC — критерий выполнен, но внутри
  задачи {{e13.P.within}}: прирост — про размеры патча и модель, не про попытку. Состав признаков зависит от формата
  логов.
- **Бустинг (рецензия, E15).** Градиентный бустинг по «модель + log шагов» даёт {{e15.ne.MNgbm}} — не лучше
  регрессии; бустинг `M+S` — {{rev.gbm.ms}} по рецензии, хуже регрессии. Нелинейность не спасает.
- **Выбор лучшей попытки по структуре (E9)** — не лучше случайного среди отправивших (`06_results_run_level.md`).
- **Самооценка с «Be honest» (E11b)** — не лучше случайного у законченных попыток (`07_results_agent_words.md`).
