# 03. Данные

## 1. Корпус лидерборда SWE-bench Verified, bash-only (основной)

- **Что это.** Публичные траектории лидерборда SWE-bench Verified в режиме bash-only: каркас mini-SWE-agent (версии
  v1.x и v2.0.0), разные LLM; связка «агент × модель» = версия каркаса × модель. Задачи — SWE-bench Verified
  (`jimenez2024swebench`).
- **Популяция — только отправленные прогоны.** Прогон, не отправивший результат (обрыв по лимиту, ошибка), исключается:
  он тривиально провальный и завышает AUROC.
- **Популяция E7 (P_all):** {{e15.all.runs}} отправленных прогонов, доля нерешённых {{e15.all.base}}.
- **Пустые патчи.** {{e15.empty.n}} отправленных прогона без изменений кода; все не решены. Модель `M+S` ставит
  {{e15.empty.top10|v}} из них в верхний дециль риска {{src:e15.empty.top10}}.
- **Основная популяция статьи (P_ne) — без пустых патчей:** {{e15.ne.runs}} прогона, доля нерешённых
  {{e15.ne.base}}. Все числа главной таблицы — по P_ne; P_all — только для сравнения.
- **Метки.** «Решено» — скрытые тесты бенчмарка (FAIL_TO_PASS и PASS_TO_PASS) прошли; агенту они недоступны.

## 4. Метки и их известный шум

- **psf/requests.** Тесты части задач обращаются к внешнему httpbin.org; его сбои дают провал при любом патче. Это
  известно (SWE-bench issue #484). Количественная оценка на лидерборде bash-only сделана в
  `own_data/LABEL_AUDIT_REQUESTS.md`; её числа не в `reports/` и в набор не входят — в статье только качественно или
  [TODO: перенести аудит в отчёт].
- **Шум оценки на повторах** (одинаковый патч — разные метки): у devstral-2512 и Qwen3-32B почти нулевой
  (`06_results_run_level.md`, §4), поэтому потолок AUROC внутри единицы около единицы.
- **Детектор заявлений G0** пропускает часть заявлений (`07_results_agent_words.md`).

## 5. Что в статью не входит

- Собственный корпус (повторы glm-4.6, остановлен по бюджету) — только диссертация, как иллюстрация.
- Итерация 1 (семантические траектории), E5–E6 (старая подвыборка заявивших успех), E12 (описание задачи) — в
  диссертацию; в статье — одной строкой в Discussion (`09_negative_results.md`).
- Внешняя валидация на AppWorld и τ²-bench — содержит нестыковки, в выводы не входит.
- DeepSWE-Preview — исключён (§2).
- GPT-5.2 в E14 — траектории в формате Responses API не разобраны.

## 6. Популяции чисел набора

У каждого числа в ссылке `[источник: …; популяция]` указано, к чему оно относится. Пометки:

| пометка в ссылке | что это |
|---|---|
| `популяция 7 732` | **популяция статьи**: отправленные прогоны лидерборда без пустых патчей (P_ne) |
| `популяция 7 864, с пустыми патчами` | все отправленные прогоны (P_all): только для сравнения или там, где пересчёт не делался |
| `…; выборка 100 сообщений` | проверка детектора G0 по ручной разметке; выборка из P_all, не пересчитывалась |
| `корпус: 7 975 траекторий, 500 задач` | корпус после разбора, включая неотправленные прогоны |
| `итерация 1: …` | популяция итерации 1 (E4) |
| `повторы KTH, …` | повторы ASSERT-KTH: две настройки вместе или одна из них; «три настройки» — только доказательство исключения DeepSWE-Preview |

| `чужая работа` | число из литературы (`docs/LITERATURE.md`) |
