# 13. Глоссарий RU / EN

Термины — как в статье. Если термин в русском тексте набора отличается от английского дословно, в статье используется
английский столбец.

| русский | English | пояснение |
|---|---|---|
| достоверность выполнения (задачи) | veracity of task completion | соответствие сданного результата (патча) фактическому исходу по скрытым тестам |
| ложный успех; ложное выполнение | false success; false completion | агент сдал результат или заявил успех, а задача не решена |
| траектория (выполнения) | (execution) trajectory | последовательность шагов агента: рассуждения, команды, выводы инструментов |
| прогон; попытка | run; attempt | одно выполнение задачи агентом; на повторах — одна из попыток единицы |
| связка «агент × модель» | agent–model combination (combo) | каркас определённой версии с конкретной LLM на лидерборде |
| настройка (KTH) | setting | каркас nano-agent с одной моделью; повторные прогоны при одной температуре |
| единица (настройка × задача) | unit (setting × task) | все попытки одной настройки на одной задаче |
| общий AUROC | pooled AUROC | AUROC по всем парам прогонов (разные задачи и модели) |
| AUROC внутри задачи | within-task AUROC | только пары прогонов одной задачи, пулом по задачам |
| AUROC внутри единицы | within-unit AUROC | только пары попыток одной единицы (одна модель, одна задача) |
| пары законченных попыток (ЗЗ) | pairs of finished attempts | обе попытки пары закончились сообщением агента без вызова инструмента |
| законченная / оборванная попытка | finished / cut-off attempt | закончилась финальным сообщением агента / оборвана лимитом шагов или иначе |
| база «попытка не закончена» | "attempt not finished" baseline | риск — сам признак «попытка оборвана»; без обучения |
| сложность задачи по другим моделям (`D`) | task difficulty from other models (ceiling) | доля нерешённых прогонов других моделей на той же задаче; потолок, к новым задачам не применим |
| идентичность модели (`M`) | model identity (one-hot) | признак связки агент × модель |
| признаки структуры (`S`) | trajectory-structure features | длина, фазы правка/проверка/прочее, повторы, ошибки команд; состав — `04_methods.md` |
| исходы собственных проверок агента (`O`) | outcomes of the agent's own checks | результат последних запусков тестов и скриптов агентом (pass, fail, error, …) |
| признаки патча (`P`) | patch features (no reference) | размеры и состав итогового диффа без эталонного патча |
| длина (`LEN`), число шагов (`N`) | length features; number of steps | базовые линии «модель + длина» и «модель + log шагов» |
| обучение на настройках вместе (T1) / внутри настройки (T2) | pooled training / within-setting training | две схемы обучения модели по траектории на повторах |
| отбор на проверку | triage for review | ранжирование сданных результатов по риску для выборочной проверки человеком |
| precision@k, recall@k | precision@k, recall@k | доля нерешённых среди верхних k% по риску; доля всех нерешённых, попавших в верхние k% |
| лифт | lift | precision@k / доля нерешённых |
| выбор лучшей из k попыток | best-of-k selection | выбрать одну попытку из k по наименьшему риску |
| случайная среди отправивших / среди законченных | random among submitted / among finished | базовые правила выбора |
| спонтанное заявление об успехе (G0) | spontaneous success claim | утверждение успеха в финальном сообщении агента |
| запрошенная самооценка | elicited self-assessment | вопрос к тому же агенту в продолжении его диалога |
| обычный вопрос (C3) / с «Be honest» (C4) | plain question / honesty prompt | вероятность в процентах, что скрытые тесты пройдут; то же с «Be honest in your response» |
| «не знает, а не скрывает» | unaware rather than concealing | наблюдение, не вывод |
| разложение дисперсии | variance decomposition | доли задачи, модели, их взаимодействия и попытки в дисперсии исхода |
| латентная / наблюдаемая шкала | latent / observed scale | доли в смешанной логистической модели / в дисперсии бинарного исхода |
| потолок AUROC внутри единицы | within-unit AUROC ceiling | наибольший AUROC внутри единицы при оценённом шуме меток |
| шум оценки | evaluation noise | разные метки у побайтно одинаковых патчей одной единицы |
| пустой патч | empty patch | отправленный прогон без изменений кода; всегда не решён |
| перенос | transfer | обучение на одних связках или формате логов, проверка на других |
| формат логов каркаса (v1 / v2) | scaffold log format (v1 / v2) | версии mini-SWE-agent v1.x и v2.0.0 на лидерборде |

| параллельная работа | concurrent work | arXiv 2611.08285 |
| кластерный бутстрэп | cluster bootstrap | повторная выборка задач (лидерборд) или единиц (повторы) |
