# Навигация и правила для агентов

Репозиторий магистерской диссертации: оценка достоверности выполнения задач LLM-агентами по структуре траектории.

- Вход: `README.md`. Пакет для рецензента: `REVIEW_PACKET.md`. Документация: `docs/` (этапы — `docs/EXPERIMENTS.md`,
  воспроизведение — `docs/REPRODUCE.md`). Данные: `DATASET_CARD.md`. Состав репозитория: `INVENTORY.md`.
- Прежнее задание (итерация 1) — `archive/AGENTS_iteration1.md`; оно устарело и инструкцией не является.

Правила:
- Не менять данные, метки, `outputs/` и отчёты `reports/` без явного задания автора.
- Никаких платных вызовов API без явного задания автора.
- Ключи API — только в переменных окружения; никогда не записывать их в файлы.
